# Estimating-ShearModulus-elastography-images

Classification of tissue-mimicking phantoms by shear modulus (stiffness) from Scanning Laser Doppler Vibrometry (SLDV) wave-field data, using a convolutional neural network (CNN) pre-trained on synthetic waves and fine-tuned on measured data.

Developed during my Master's thesis in Biomedical Engineering. Published in:

> *Journal of the Mechanical Behavior of Biomedical Materials*, 170 (2025) 107079.

## Background

Diseased tissue is often stiffer than healthy tissue, so stiffness is a useful biomarker. Elastography measures it indirectly: a mechanical wave is sent through the tissue, and the way the wave travels (speed and wavelength) depends on the shear modulus. Stiffer material carries faster waves with longer wavelengths.

SLDV is a non-contact optical technique that records the surface vibration of a sample at many points, giving a spatio-temporal image of the wave field. This project learns the relation between those wave fields and the stiffness of the material.

A practical problem is the lack of public SLDV datasets. To address it, the network is first trained on synthetic wave fields generated from an analytical model, and then fine-tuned on a small set of real measurements.

## What this repository does

- Generates synthetic wave fields from an analytical model (Green's function of a vibrating source in an elastic medium, after Royston et al., 2021).
- Pre-trains a CNN on the synthetic data.
- Fine-tunes the CNN on measured SLDV data from 5 silicone (Ecoflex) phantoms with different stiffness.
- Evaluates two tasks: binary classification (soft vs. stiff) and five-class classification (one class per phantom).

## Method

1. **Synthetic data.** Wave fields are simulated for a range of shear moduli, with the same grid and frequency content as the measurements.
2. **Measured data.** SLDV acquisitions of 5 Ecoflex phantoms. Each acquisition is divided into 4 sectors, giving 13 acquisitions x 4 sectors = 52 samples per class.
3. **Input.** Each sample is an array of size 71 x 11 x 2 (spatial grid, with two channels).  
4. **Model.** A CNN classifier. 
5. **Training.** Pre-training on synthetic data, then fine-tuning on measured data. Two train/test splits were evaluated: 80:20 and 70:30.
6. **Evaluation.** Accuracy and AUC on held-out measured data.

## Results

| Task | Without synthetic pre-training | With synthetic pre-training |
|---|---|---|
| Binary classification (soft vs. stiff) | 57.6 % | **84.4 %** (AUC about 0.92) |
| Five-class classification | 54.7 % | **76.7 %** |

Synthetic pre-training clearly improves performance when only a small measured dataset is available.

## Limitations

- **Classification, not regression.** The model assigns a phantom to a stiffness class. It does not output a continuous shear modulus value.
- **Sector-level split.** Samples are sectors of the same acquisitions. If sectors from one acquisition appear in both training and test sets, results can be optimistic.
- **Simple phantoms.** Homogeneous, isotropic silicone phantoms. Real tissue is heterogeneous, anisotropic and viscoelastic.
- **Small test set.** About 50 test samples (about 10 per class), so confidence intervals are wide.
- **No classical baseline.** The CNN was not benchmarked against classical inversion methods (for example, local frequency estimation).
- **Measured data not public** (see below).

## Installation

Requires Python 3.9 or later. 

```bash
git clone https://github.com/SilviaLeccabue/Estimating-ShearModulus-elastography-images.git
cd Estimating-ShearModulus-elastography-images
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
